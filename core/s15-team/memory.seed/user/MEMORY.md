## reply-style
updated: 2026-10-02T09:04:00
last-read: 2026-10-02T10:04:00
reads: 1
回答先给结论再给理由，不要先铺三段背景。代码注释用中文，变量名保持英文。不确定的地方直接说不确定，不要用「可能」「大概」糊过去——不确定就去看代码。

## commit-lang
updated: 2026-10-02T09:03:00
last-read: 2026-10-02T10:03:00
reads: 2
提交信息和 PR 描述用中文，代码注释也用中文，但不要解释显而易见的行（i++ 不用注释）。注释只写「为什么这么写」，不写「这行在做什么」。
