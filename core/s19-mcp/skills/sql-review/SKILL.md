# SQL 审查清单

按顺序过一遍，命中就停。

## 1. 索引能不能用上

- `WHERE` 里对字段做函数运算或隐式类型转换，索引直接失效。
- 前导模糊 `LIKE '%x'` 走不了索引，只能全表扫。
- 复合索引按最左前缀匹配，`(a, b)` 用不到只查 `b`。

## 2. 要扫多少行

- `EXPLAIN` 看 `rows`，超过十万先问清楚业务上有没有别的办法。
- 深分页用游标（`WHERE id > ?`），别用大 `OFFSET`。

## 3. 有没有 N+1

循环里查库，一次请求几百条 SQL。改成批量 `IN`，或者一次 join 拿回来。

## 4. 写操作

- 批量更新分批提交，每批几千行。
- 大事务拆小，别长时间锁表。
